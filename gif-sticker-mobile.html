WebP compression

Select your exported WebP. Merges identical consecutive encoded frames, preserving pixels, transparency and timing. It may not reduce every file below 512 KB.

GIF → WebP uses the browser’s lossy encoder. “Fit” keeps resolution and timing but may change pixels; it is not lossless.

WebP works offline and loops with transparency. Telegram animation requires WebM. WebM export runs on this device when its browser supports VP9 encoding; otherwise use WebP or animated PNG. Both new exports resize proportionally so the longest side is exactly 512 px. WebM fits the whole loop into 3 seconds and tries lower bitrates to fit below 256 KB.

Quick helpPick a background colour, adjust tolerance, then remove it. Remove outside white protects white inside a closed dark outline. A gap in the outline can let removal reach the interior; use a lower tolerance, a rectangle, or Restore brush. Select region highlights only the connected area you tap. With all frames, it finds that colour region from the same tap position separately in each frame. Rectangles stay in the same position when applying to all frames. Restore brush paints original details back, even after colour removal. Crop to region trims the animation. Undo restores the last edit, including a crop. Original frame timing is preserved; animation exports loop forever. Large GIFs can use considerable phone memory. All processing happens locally; no internet or account is needed for this file. WebM requires a browser with WebCodecs VP9 support. If your file manager shows only a preview, choose Open with a browser.
